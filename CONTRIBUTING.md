# Contributing

Corrections are welcome, especially where the advice is wrong, out of date on a newer OS or tool version, or too specific to one setup to be general.

1. Open an issue or pull request that says what is wrong and, if you can, how you checked it.
2. Run `python3 validate.py` (frontmatter and referenced paths).
3. Keep the tone of general guidance: say "in the author's experience" for observations from one setup.
4. Do not include secrets, personal data, absolute local paths or account identifiers.
